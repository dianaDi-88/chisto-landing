# ЧИСТО. — демонстрационный лендинг клининговой компании

Русскоязычный адаптивный одностраничный сайт. HTML, CSS, JavaScript без сборки и зависимостей.

## Запуск
Откройте `index.html` в браузере. Для локальной разработки можно использовать VS Code Live Server или `python -m http.server 8000`.

## Функции
- Адаптивная вёрстка и мобильное меню
- Интерактивный калькулятор ориентировочной стоимости
- Слайдер сравнения изображений (демонстрационная механика, одно исходное фото)
- FAQ и валидация формы

## Публикация
Загрузите файлы в GitHub-репозиторий и импортируйте проект в Vercel как статический сайт (без build command). Также можно опубликовать на GitHub Pages.

## Важно перед реальным коммерческим использованием
- Заменить вымышленные тарифы, отзывы и утверждения о сервисе проверенными данными заказчика.
- Подключить обработчик заявок (например, Formspree или серверную функцию), защиту от спама и политику конфиденциальности.
- Заменить демонстрационное сравнение «до/после» реальными фотографиями с разрешениями.
- Проверить права использования фотографий с Unsplash, а также доступность внешних изображений.
- Уточнить юридические реквизиты, город обслуживания и контактную информацию.
